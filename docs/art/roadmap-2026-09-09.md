## 1. 立即（半天）：A2 母本集的挑選工具

A2 計畫 Task 4 的 `select_masters.py` 尚未做，而 §9.3 已證明沒有它就無法追溯母本來源（鐵人換張、大熕船在 `game/assets` 是被拒的圖）。

1. `art/scripts/select_masters.py`：帶編號印樣、`--pick <id>=<n>`、`--apply`（複製到 `02_selected/flat/`）、`--status`；選擇寫入 `art/manifest/master_set.json`（`{asset_id: {stage, file, picked_at}}`）。
2. `postprocess.py` 優先讀 `master_set.json` 指定的候選，沒有才退回 `files[0]`；`source_stage` 欄位併入此機制後移除。
3. 鐵人軍、大熕船各補 4 張：用 `a2x_flux2_edit` 餵史料參考（明代札甲、中式硬帆），prompt 只給風格。
4. 圖示 6 個重出：framing 改「只有符號、無底框、無背景」；底框交給 UI 主題（見 §4）。

**產出**：`master_set.json` 有 33 筆、`02_selected/flat/` 33 張。挑選是人工——由你在印樣上點號碼，我執行。

## 2. 接著（半天）：母本過閘門、進 `game/assets`

1. `postprocess.py --stage flat` → `03_processed/`（RGB 量化 + 描邊 1px——扁平風格下 2px 太重，需實測 1 vs 2）。
2. 三道檢查：`silhouette.py`（同陣營剪影相似度 ≤ 0.93）、`check_lighting.py`（分光線應讓 L2 全過——這是驗證「風格幾何化執行 L2」的機會）、色票測試。
3. 替換 `game/assets/chapter01/` 33 張，`godot --headless --import`，全套測試。
4. `docs/art/A2-master-set.md` 補第二批紀錄。A2 閘門要求「連續三批」：第二、三批在 §3 的分件與 §5 的肖像產出時累積。

## 3. 並行（1–2 天）：M1 收尾——地圖改 TileMap

規格已寫（`docs/superpowers/specs/2026-09-09-m1b4-tilemap-map-design.md`，草案）。

1. 先過 brainstorming 把 §6 兩個待決策定掉（磚 32 或 48；路徑格卵石或素沙），再寫實作計畫（`docs/superpowers/plans/2026-09-09-m1b4-tilemap-map.md`，TDD）。
2. 實作順序：`map.json` schema + `core` 路徑折線 → `Path2D`（測試：改一個 waypoint 兩邊同時變）→ `TileMapLayer` 鋪地 → 擺件層 + L1 陰影 → 潮汐換格子 → 建塔點由資料指定。
3. 擺件資產：榕樹、竹叢、礁石、林投用扁平風格重出（`experiment_props.json` 改風格區塊），聚落沿用 chapter01 的 `prop_settlement`。
4. 紙紋 shader（`paper_ink.gdshader`）接進戰場：layer 40 描邊 + 紙紋只作用地圖、layer 100 純紙紋蓋全部（A2x §2.4 的兩層結論）。**M2 要量它在中階 Android 的幀率**。

## 4. 之後（1 天）：分件動畫量產

1. 拆件參數進清單：每個人物資產加 `"puppet": {"hem", "leg_top", "hip", "split_x"}`（母本像素座標，人看一次印樣填），`walk_pack.py --from-manifest` 批次拆件並 `--install`。
2. 塔的人物（銃樓火繩槍手、鏢手、壯丁）與敵人共用同一套分件邏輯；建物類（砲位、陷阱、柵欄）不拆。
3. 動作曲線：行走（已有）、攻擊（軀幹前傾 + 武器臂角度）、受擊（整體後退 + 白閃，L5）、死亡（整體倒下旋轉 + 淡出）。全部是程式曲線，零新資產。
4. 執行期成本：每單位 3 個 `Sprite2D`，150 單位 450 個繪製項——列入 M2 量測項目。
