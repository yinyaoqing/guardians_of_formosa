## 0. 本規格的敘事立場

在寫任何機制之前必須先定案史觀，否則機制會自己長出立場。

### 0.1 採用的史觀

**核心命題：荷蘭東印度公司與鄭氏集團，對這座島而言是兩個外來統治集團的政權交替，不是「解放」。**

此立場的依據：

- **史明《台灣人四百年史》**：明確主張鄭氏王朝與荷蘭人「幾乎是同樣，無非是一個外來統治集團」，本質上是外來的殖民統治者。全書以「人民史觀」書寫，站在被統治者立場。本專案第一章的敘事骨架直接採用此判斷。
- **曹永和「台灣島史」觀**：以島嶼本身及其上的人群為敘事主體，而非以任何一個統治政權的興衰為主軸。此觀點決定了本章「玩家究竟在守什麼」的答案。
- **歐陽泰（Tonio Andrade）《決戰熱蘭遮》**：提供戰術層級的細節重建，並修正「歐洲軍事必然優越」的成見——鄭軍的弓箭射速、火砲操作與圍城工程在實戰中並不遜色。此書是本章戰鬥數值的主要參照。
- **江樹生譯註《熱蘭遮城日誌》**：一手史料，事件日期、兵力、船名、原住民各社動向的權威來源。

### 0.2 由此推導出的三個設計決定

這三點是本章與一般「打荷蘭人／打鄭成功」題材的根本差異，也是本作的辨識度來源。

**決定一：塔＝島上的人，不是政權。**

玩家蓋的塔是新港社獵人、大員街上的漢人壯丁、荷蘭砲手、被役使的奴工。這些人在 1661 年被兩個政權輪流徵用。

**因此當關卡推進、來襲方從鄭軍換成別的勢力時，玩家手上的塔基本不變。** 機制本身就把史觀說完了：政權來來去去，島上的人一直都在。這比任何過場文字都有效。

**決定二：不設「選邊站」分支。**

先前發想中的「選荷方或鄭方視角」在此史觀下是錯的——它預設玩家該替某個殖民政權感到光榮。改為**固定的視角轉移**：玩家的位置從頭到尾在島上的人身上，鏡頭跟著他們走，兩個政權在鏡頭裡進進出出。

**決定三：勝利條件是「救到多少人」，不是「城有沒有守住」。**

熱蘭遮城必定陷落，這是史實。但**不採用強制失敗關卡**——那既挫折又暗示玩家該替 VOC 惋惜。

改以星等承載歷史（詳見 §4.6）：撐過波次即通關，星等取決於**平民撤離人數與聚落存活數**。城池易主是過場演出的既定事實，玩家的成就感來自保住了多少人。

## 1. 地理考據：台江內海

### 1.1 關鍵前提：今日地形完全不能用

1823 年曾文溪改道，大量泥沙灌入台江內海，加上長期淤積，**今日的台南安平一帶已全部陸化**。今天站在安平古堡看到的地貌，與 1661 年沒有任何參考關係。

**地圖必須依 17 世紀荷蘭古地圖繪製**，主要參照：

- Johannes Vingboons 繪製的大員鳥瞰圖系列（荷蘭國家檔案館 VOC 檔案）
- 1636 年《大員港市鳥瞰圖》
- 1644 年熱蘭遮城與市鎮實測圖

### 1.2 地形結構

台江內海是一片被西側沙洲鏈圍出的潟湖。由北而南：

| 地名 | 荷蘭文獻名 | 性質 | 戰役中的角色 |
|---|---|---|---|
| 加老灣嶼 | — | 沙洲 | 鹿耳門水道北岸 |
| **鹿耳門水道** | Lakjemuyse | **淺水道** | 荷方判定大船不可通行，**故未設防**。鄭軍由此突入 |
| **北線尾** | Baxemboy | 狹長沙洲 | 5/1 陸戰戰場；南端有荷方海堡（已半廢） |
| **大員水道** | — | 主航道 | 荷方唯一設防的入口，砲火完整覆蓋 |
| **一鯤鯓** | Tayouan | 沙洲島 | **熱蘭遮城 + 大員市鎮**所在 |
| 二～七鯤鯓 | — | 沙洲鏈 | 向南延伸，人煙稀少 |
| **赤崁** | Sakam / Provintia | 本島岸邊 | **普羅民遮城**、漢人聚落、通往內陸 |

台江內海東岸往內陸，即為西拉雅四大社：**新港社（Sinckan）、目加溜灣社（Baccloan）、蕭壠社（Soulang）、麻豆社（Mattau）**。

### 1.3 為何鹿耳門是整場戰役的關鍵

三個條件同時成立才使鄭軍得以突入，缺一不可。三者都應在關卡中成為可玩機制：

1. **情報**：通事**何斌**叛逃投鄭，帶去水道測深資料與航道圖。荷方的天險是「荷方以為的天險」。
2. **潮汐**：1661 年 4 月 30 日為農曆四月初一，**朔日大潮**，水位達最高。鄭軍船隊趁高潮越過淺灘。
3. **設防盲點**：荷方所有砲火配置都朝向大員水道。

### 1.4 熱蘭遮城結構

- **內城**：近正方形，三層。地下層為倉庫，地上兩層，四角各設稜堡。
- **外城**：接於內城北側的長方形城郭，設 2 座稜堡 + 1 座半圓堡；1660 年增建東北稜堡，最終形態共 7 座稜堡。
- **建材**：荷蘭運來的紅磚，以糯米汁、糖水、砂、蚵殼灰調製的三合土黏合。
- **烏特勒支堡（Redoubt Utrecht）**：位於城堡側後方的沙丘高地上，距城約一個火槍射程。**此處是全城的致命弱點**——佔領它即可俯瞰並砲擊城內。
- **稜堡的防禦邏輯是交叉側射火網（flanking fire）**，不是「牆很厚」。此點必須反映在塔的機制上（見 §4.0），否則稜堡只是好看的背景。
- **大員市鎮**：城堡東北側的棋盤式街區，漢人商販與 VOC 職員混居。

## 2. 事件序考據

以西曆列出。日期採《熱蘭遮城日誌》系統（江樹生譯註）與中文學界通行版本。英文維基另有一組早約四週的日期，係曆法換算差異所致，**本專案一律採下表**。

### 2.1 第一階段：突入（1661/4/22 – 5/6）

| 日期 | 事件 |
|---|---|
| 4/22 | 鄭軍於金門料羅灣集結。號稱 25,000 人、數百艘船 |
| 4/23 | 抵澎湖，等待順風 |
| 4/29 夜 | 冒險啟航渡黑水溝 |
| **4/30 清晨** | **經鹿耳門水道突入台江**（農曆四月初一大潮）。於禾寮港登陸 |
| **5/1** | **北線尾之戰**：荷方隊長 Thomas Pedel（鄭方記為「拔鬼仔」）率約 240 人登陸迎擊，遭鄭軍水陸夾擊，Pedel 與約 118 人陣亡。同日**台江海戰**，荷艦 Hector 號因火砲引燃彈藥庫爆炸沉沒 |
| 5/2–5/5 | 鄭軍圍普羅民遮城；佔領大員市街，切斷城堡與本島聯繫 |
| **5/6** | **普羅民遮城投降**（守將 Valentijn） |

### 2.2 第二階段：強攻與封鎖（1661/5 – 8）

| 日期 | 事件 |
|---|---|
| 5/24 | 牧師 Antonius Hambroek 入城勸降，未果 |
| **5/25** | **鄭軍首次強攻熱蘭遮城**，動用 28 門火砲。遭稜堡交叉火力反擊，傷亡逾千人後改採長期封鎖 |
| 6–8 月 | 圍城僵持。**鄭軍糧食嚴重不足**（何斌謊稱數日可達，導致補給準備不足），被迫將大量部隊分散至南北路屯田 |
| 6/22 | 荷方 Klenck 率兩船自巴達維亞出發援台 |
| 7/30 | Klenck 抵大員外港，見情勢不利，**逕自逃往日本** |
| **8/12** | **Jacob Cauw 率九艘船艦抵台**，卸下約 50 名士兵與糧彈 |
| 8/15 | 荷艦 Urk 號於蕭壠溪擱淺，42 人被俘 |

### 2.3 第三階段：原住民的反擊（1661/8 – 9）

**此段是本章敘事的重心，一般敘述常略過。**

鄭軍屯田直接佔用原住民鹿場與耕地，並徵調勞役，遂與各社爆發全面衝突。依《熱蘭遮城日誌》所載：

| 地點 | 事件 |
|---|---|
| 諸羅山 | 鄭軍約 800 人陣亡 |
| **大肚王國** | 大肚王甘仔轄·阿拉米（Camachat Aslamie）系統的勢力殲滅楊祖部隊，該部 3,000 人僅存約 200 人 |
| 瑯嶠 | 鄭軍 700–800 人被殲 |

**考據標註**：以上數字出自荷方紀錄，荷方有誇大鄭軍損失以自我安慰的動機，遊戲中應作為「規模可觀的抵抗」處理，不宜將具體數字當作史實呈現。但**衝突確實發生且規模不小**這一點，荷、鄭、原住民三方史料互證無疑。

### 2.4 第四階段：崩解（1661/9 – 1662/2）

| 日期 | 事件 |
|---|---|
| 9/9 | 援軍艦隊返回大員，卸下 15,000 磅火藥與火砲 |
| **9/16** | **荷方主動出擊台江內海反攻，慘敗**。Koukercken 號、Kortenhoef 號沉沒，陣亡 128 人 |
| 12/3 | Cauw 率五艘戰艦名義上前往福州聯清，滯留澎湖 |
| **12/10** | **Cauw 逕自逃回巴達維亞**，城內士氣崩潰 |
| 12/16 | 德意志裔士官 Hans Jurgen Radis 叛逃至鄭軍，提供城防情報，指出烏特勒支堡的關鍵地位 |
| **1662/1/25** | **鄭軍集中火砲猛擊烏特勒支堡**，一日發射約 2,500 發（其中約 1,700 發針對該堡），三面牆體崩毀，當夜守軍自爆棄守。熱蘭遮城自此完全暴露 |
| 1/27 | 荷方評議會決議停止抵抗 |
| **2/1** | **簽訂條約**（荷方 18 條、鄭方漢文 16 條）。准許 VOC 人員攜帶個人財物離開 |
| 2/9 | 約 2,000 名荷蘭人登船 |
| 2/17 | 揆一（Frederick Coyett）率艦隊離台 |

### 2.5 雙方數據

| 項目 | 鄭軍 | 荷方 |
|---|---|---|
| 指揮官 | 鄭成功 | 揆一（Frederick Coyett） |
| 主要將領 | 馬信、陳澤、周全斌、何義、陳蟒、楊朝棟、劉國軒 | Thomas Pedel（陣亡）、Valentijn、Jacob Cauw |
| 兵力 | 25,000（荷方估計；一說實際渡海戰兵約 11,700） | 熱蘭遮城 1,100 人（含 905 名士兵）；普羅民遮城 140–400 人；援軍 700 人 |
| 損失 | 陣亡 3,000–5,000；另有大量因疾病與飢餓折損 | 陣亡 632、被俘 568 |

**城內非戰鬥人口**：熱蘭遮城內另有約 547 名奴隸、218 名婦孺。**這 547 人必須出現在遊戲中**——他們是荷蘭殖民地的真實構成，把殖民地畫成純粹的歐洲人前哨是美化。

## 3. 物質文化考據

美術資產為 AI 生成，故本節同時作為**生成提示的規格書與錯誤防呆清單**。AI 對 17 世紀東亞的預設輸出錯誤率極高，下列「常見錯誤」欄必須寫入美術 prompt 的負面詞。

### 3.1 荷蘭東印度公司

**武器**

| 項目 | 規格 |
|---|---|
| 火繩槍（musket） | 主力。槍管近 1.2m，射速慢，早期需槍叉支撐。少量燧發槍（snaphaan） |
| 彈藥帶（bandolier） | 斜掛，繫 8–12 個木製定裝藥管（俗稱「十二使徒」）、引藥瓶、彈袋 |
| 長柄兵器 | 長矛（pike，比重已下降）、戟（halberd，士官持） |
| 短兵 | 闊刃劍、短劍 |
| 手榴彈 | 陶製或鐵製，守城時自稜堡投擲 |
| 城砲 | 鑄鐵／青銅前膛砲，以 24 磅、12 磅為主。守城時大量使用霰彈 |

**服裝**

- 士兵：亞麻襯衫、及膝馬褲、長襪、皮鞋、寬邊氈帽或草帽。外罩短外衣。
- 士官與軍官：深色羊毛外衣、白色翻領（falling band）、寬邊帽、腰間或肩上飾帶。
- 揆一等高階官員：黑衣白領的正式肖像式樣。
- **奴隸與勞役者**：簡易亞麻纏腰布，東南亞與印度來源。

> **常見錯誤（負面 prompt）**：全身板甲、胸甲騎兵、莫里恩頭盔（1661 年已過時）、歐洲本土冬季厚呢軍裝、統一制服。VOC 在亞洲**沒有制式軍服**，且此處是亞熱帶——服裝應鬆散、輕薄、雜色、明顯磨損。

### 3.2 鄭軍

**武器**

| 兵種 | 裝備 |
|---|---|
| **鐵人軍** | 全身鐵甲 + 鐵面罩，**赤足**。配斬馬刀（雙手長刀）、弓箭、藤牌、腰刀 |
| **藤牌兵** | 藤牌 + 腰刀。低姿快速突擊 |
| **銃卒** | 鳥銃（火繩槍） |
| **弓箭手** | 射速遠高於火繩槍。歐陽泰特別指出，鄭軍弓箭在實戰中的壓制效率不遜於荷方火槍——**這必須反映在數值上**，不能把鄭軍設計成「用人海換火力」 |
| 火砲 | 紅夷大砲（仿製與繳獲）、佛郎機、連環火砲。北線尾一役即配備 200 門連環火砲；圍城時集中 28 門重砲 |
| 戰船 | 大熕船（載重砲主力艦）、犁繒船（快速接舷）、鳥船。數百艘規模 |

**服裝**

- 明制號衣（紅、藍為主）、笠形鐵盔或藤盔、布纏腿、赤足或草鞋。
- **鄭軍慣於赤足**，僅頭部與軀幹著甲，這是荷方紀錄中特別提到的視覺特徵，應成為美術辨識點。
- 將領：明制山文甲或鎖子甲、盔纓。
- **髮式為明制束髮，未剃髮。**

> **常見錯誤（負面 prompt）**：辮髮（清制，鄭軍恰恰是反清的一方，畫成辮子是史實硬傷）、清代綠營號衣、日本足輕具足、泛用「東方戰士」設計。

### 3.3 西拉雅族

依陳第《東番記》（1603）與 VOC 檔案。

**武器**

- **鏢**：竹柄、鐵鏃，長五尺餘，極銳利。《東番記》載「試鹿鹿斃、試虎虎斃」。這是主戰兼狩獵武器。
- 竹弓與箭。
- 短刀。
- 無城郭。**以善走著稱**，機動性極高。

**服裝與外觀**

- 男子：「不冠不履，裸以出入」。或圍鹿皮、布。束髮、拔鬚、耳飾。部分刺青。
- 女子：短衣、圍裙。
- 《東番記》另載，獲贈漢人舊衣會珍藏，但少穿著。
- **頭目手持 VOC 頒發的藤杖**（銀質杖頭刻公司徽記），為 1636 年起「地方會議」（Landdag）制度的權力信物。**此物件是荷蘭間接統治的具象化，應成為關鍵美術符號。**
- 新港社因傳教影響，部分族人能書寫羅馬字拼寫的西拉雅語（即後世所稱「新港文書」）。

> **常見錯誤（負面 prompt）**：泛用「原住民」造型、羽毛頭飾（北美刻板印象）、與台灣其他族群的服飾混用（尤其應避免套用泰雅、排灣等的紋樣）、過度戲劇化的部落彩繪。

### 3.4 三方陣營的視覺辨識規格

依架構規格 §4.7，單一敵人貼圖上限 128×128。在此尺寸下必須靠**剪影**辨識，不能靠細節：

| 陣營 | 剪影特徵 | 主色 |
|---|---|---|
| VOC | 寬邊帽 + 斜掛彈藥帶的胸前橫線 | 米白 / 黑 / 暗紅 |
| 鄭軍 | 笠形盔的三角剪影 + 赤足 | 朱紅 / 深藍 |
| 鐵人軍 | 全包覆的厚重方形剪影 + 長刀 | 鐵灰 |
| 西拉雅 | 裸身修長剪影 + 長鏢斜持 | 膚色 / 鹿皮褐 |

## 4. 關卡設計

第一章拆為三個關卡（對應架構規格中「一個關卡 = 一張地圖」的定義）。M1 垂直切片先做 **1-1**，1-2 與 1-3 列入 M3 內容擴張。

### 4.0 塔種

塔＝島上的人（見 §0.2 決定一）。M1 實作前三種，第四種列 M3。

| # | 塔 | 定位 | 三級升級 | M1 |
|---|---|---|---|---|
| 1 | **銃樓**（火槍位） | 單體高傷、低射速，有明顯裝填節奏 | 火繩槍手 → 排槍齊射 → 稜堡砲位 | ✅ |
| 2 | **獵寮**（新港社獵人） | 低傷、短射程，施加減速與流血 | 鏢手 → 鹿陷阱（路徑陷阱） → 火燒獵場（範圍 DoT） | ✅ |
| 3 | **柵欄**（大員街民壯丁） | 出兵擋路，對應架構 §4.1 的 `blocked_by` | 竹柵 → 刀盾壯丁 → 藤牌隊 | ✅ |
| 4 | **稜堡砲位** | 高造價範圍傷害，**有最小射程** | 12 磅砲 → 24 磅砲 → 霰彈交叉火網 | M3 |

**稜堡砲位的設計意義**：其三級「交叉火網」需與另一座稜堡砲位相鄰才觸發加成，直接把 §1.4 的 flanking fire 原理做成機制，而不是當背景畫。

### 4.1 敵種

| 敵人 | 特性 | 教學目的 |
|---|---|---|
| 銃卒 | 標準單位，遠程微量傷害 | 基準 |
| 藤牌兵 | 快速，**對投射物高抗性** | 迫使玩家改用範圍或陷阱 |
| 弓箭手 | 遠程，**優先攻擊玩家的 blocker** | 教「擋路兵需要火力掩護」 |
| **鐵人** | 高物理護甲、移動慢 | 教破甲與範圍傷害；純單體塔打不動 |
| 掘壕隊 | **目標是塔而非終點** | 打破「敵人只會走到底」的預期 |
| 大熕船 | 走水路，不吃陸路 | 等同「飛行單位」，需水路覆蓋 |

依架構規格 §4.3，所有抗性一律走 `DamageSystem`，藤牌的投射物抗性以資料定義的護甲類型實作，不得寫特例。

### 4.2 關卡 1-1：鹿耳門．大潮

**Level 1-1: The Spring Tide at Lakjemuyse**（1661/4/30）

- **玩家身分**：大員水道砲台的守夜哨組——荷蘭砲手、被徵召的漢人壯丁、受僱的新港社嚮導。
- **地圖**：北線尾南端至一鯤鯓北端，俯瞰兩條水道。
- **核心機制：潮汐。**

| 潮位 | 效果 |
|---|---|
| 低潮（第 1–4 波） | 鹿耳門水道封閉，敵人只能走**大員水道**——該路徑砲火覆蓋完整 |
| **高潮（第 5 波起）** | **鹿耳門水道開通**，出現一條全新且無任何既有防禦覆蓋的路徑 |

HUD 上有一條潮位條，從第一波起就緩慢上升，**玩家看得見它要來**。

**教學價值**：這是全遊戲的第一關，它教的不是「蓋塔擋路」，而是**「路徑會改變，要保留資源」**——一個大多數塔防要到第 10 關才教的觀念。而它之所以能放在第一關，是因為史實本來就長這樣。

**敘事**：關卡開始時，玩家可看到荷方所有火砲都朝著大員水道。何斌的名字在開場對話中出現一次，不解釋。當鹿耳門開通時，玩家自己會懂。

### 4.3 關卡 1-2：北線尾．沙洲

**Level 1-2: The Sandbar**（1661/5/1）

- **玩家身分**：Pedel 隊中的 240 人。
- **地圖**：狹長沙洲，**兩端各有一個入口**。
- **核心機制：水陸夾擊。** 敵人自沙洲一端登陸推進的同時，鄭軍船隊沿沙洲側翼航行，可在任意點卸下部隊。玩家的防線沒有「後方」。
- **事件演出**：戰鬥中段，海面上 Hector 號爆炸——不是玩家能影響的事件，是背景中的一聲巨響與一根火柱。
- **Boss**：陳澤。
- **教學價值**：教多路徑與側翼，並打破「防線有前後之分」的直覺。

### 4.4 關卡 1-3：熱蘭遮．九個月

**Level 1-3: Nine Months**（1661/5 – 1662/2）

長關，分四階段，**單一關卡內完成一次完整的攻守逆轉**。

| 階段 | 對應史實 | 機制 |
|---|---|---|
| **一、強攻** | 5/25 首次強攻，28 門火砲 | 標準高強度波次。稜堡交叉火力有效，玩家會贏得很漂亮 |
| **二、封鎖** | 6–8 月圍城與飢荒 | **資源產出大幅下降**，敵人卻不停歇。玩家被迫拆塔換資源。此階段的敵人是經濟，不是兵 |
| **三、援軍與反攻** | 8/12 Cauw 抵達、9/16 出擊慘敗 | 玩家獲得一次性大量資源與「反攻」主動技能。**使用它會讓後續難度顯著上升**——這是設計上的陷阱，也是史實 |
| **四、烏特勒支堡** | 1662/1/25，2,500 發砲彈 | 地圖上的一座玩家塔位（烏特勒支堡）成為敵方集火目標。它被摧毀後，全城防禦獲得永久性減益 |

**結局**：無論玩家表現如何，過場演出 2/1 簽約、2/9 登船。**星等取決於期間撤離的平民數量。**

### 4.5 資源

單一資源：**銀**。

理由：架構規格的 M1 目標是驗證核心迴圈，雙資源會同時增加 UI、平衡與測試成本。1-3 的封鎖階段已足以承載資源壓力的敘事，不需要第二種資源來表達飢荒。

### 4.6 勝敗與星等

依 §0.2 決定三：

| 星 | 條件 |
|---|---|
| ★ | 撐過所有波次 |
| ★★ | 平民撤離數 ≥ 門檻 |
| ★★★ | 未失去任何一座聚落建物 |

「平民撤離」為關卡中沿路徑移動的中立單位，敵人會攻擊他們，玩家的塔可以保護他們。**這是玩家真正在防守的東西。**

## 5. 考據存疑處

誠實標註，避免把爭議寫成定論。這些地方在遊戲中應以「傳說」或留白處理。

| 事項 | 問題 |
|---|---|
| **Hans Jurgen Radis 叛逃** | 僅見於揆一《被遺誤的台灣》。鄭方史料完全無載，且揆一寫作動機是為戰敗開脫。**應處理為城中流傳的說法，非確定事件** |
| **Hambroek 勸降** | 清代《台灣外記》與荷方戲劇文本均有大幅文學加工，細節不可靠 |
| **兵力 25,000** | 荷方估計值。一說實際渡海戰兵約 11,700 |
| **原住民殲滅鄭軍的數字** | 出自《熱蘭遮城日誌》，荷方有誇大動機。衝突規模可觀為確定事實，具體數字不宜呈現 |
| **鐵人軍是否參與北線尾** | 規模與參戰與否於學界有爭議 |
| **地形** | 今日安平地貌完全不可參照，必須依 17 世紀荷蘭古地圖 |
| **日期系統** | 中英文文獻存在約四週的曆法換算落差，本規格統一採《熱蘭遮城日誌》系統 |

## 7. 待決策事項

1. **1-1 的玩家身分**是否要明確標示為「荷方哨組」。標示清楚較誠實，但會讓第一關的代入感偏向殖民方；不標示則模糊。傾向標示，靠 §0.2 決定一的塔種設計來中和。
2. **平民撤離單位**在 1-1 是否就要出現，或延到 1-2。若 1-1 就有，第一關要教的機制數量偏多。
3. **1652 年郭懷一事件**是否要進開場鋪陳。此事件解釋了漢人移民為何倒向鄭軍，以及原漢裂痕本身是 VOC 統治術的產物——對史觀完整性重要，但增加開場的資訊量。
4. **英文版敘事框架**：先前發想提及對國際市場弱化政治框架。本章的史觀是內容的骨架而非包裝，弱化會使設計失去支點。建議英文版保留完整史實，僅在商店頁文案上以「a contested island」等表述降低政治聯想。
